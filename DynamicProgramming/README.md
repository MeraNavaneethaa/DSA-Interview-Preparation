
Dynamic Programming (DP)

Dynamic Programming is an optimization technique used to solve complex problems.

It breaks a big problem into smaller subproblems and stores their results.

This avoids solving the same problem again and again.

------------------------------------------------

Key Idea

Solve each subproblem once and store the result.

This improves performance significantly.

------------------------------------------------

Two Main Techniques

Memoization

Top-down approach.
Store results of recursive calls.

Tabulation

Bottom-up approach.
Build solutions using a table.

------------------------------------------------

Example Problems

• Fibonacci sequence
• Knapsack problem
• Longest Common Subsequence
• Coin change problem

------------------------------------------------

Why Dynamic Programming is Important

Many difficult problems become efficient using DP.

Without DP:
Time complexity may be exponential.

With DP:
Time complexity becomes polynomial.
